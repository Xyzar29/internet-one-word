One word for the whole internet: **feral**.

Wild, untamed, unmoderated by nature, and impossible to house-train. It
makes you laugh, then nod.

## The entry

`main.ts` writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

```
feral
```

5 characters, one word, no explanation needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
